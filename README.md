# thepadelbooks.com — build source
Python generator for the site (not served). `cd build && python3 build.py out`, then copy out/*.html (except index.html, which is edited directly on main), out/journal.css and out/sitemap.xml to the main branch.
Graphics: diagrams.py (engine), graphics_court.py, graphics_all.py (placements + export to ~/Downloads/PADEL GRAPHICS 2027). Research notes and the graphics list are in build/research/.
