## Rules (FIP, via fip_rules.md)
- Partners/receiver anywhere on own side; only server fixed -> Rule 3 (CORRECTIONS), 6.1, 6.3. Used: australian-formation, comeback.
- Serve hitting server's partner = fault -> Rule 7d.
- Touching net / opponents' court loses point -> Rule 13a.
- Serve boxes alternate, start from right -> Rule 6.5.
- Serving order fixed per set -> 6.8; receiving order fixed per set -> 8.2, 8.3 (so receivers can't swap sides mid-set).
- 20 s between points, 90 s change of ends, 120 s end of set, no rest after 1st game of a set -> Rule 2 (rest-after-game-1 per existing padel-change-of-ends page).
- Change ends after odd games -> Rule 5.
- Server waits for receiver -> 6.10/6.11.
- Ball touching opponent's body = point lost -> 13k. Etiquette: no hitting at opponents when not in play -> CORRECTIONS.
- Own glass legal, own mesh not -> 14b, 13l.
- Ceiling before bounce = point lost; after correct bounce = correct return -> 13g, 14d (existing padel-ball-hits-ceiling page).
- Ceiling 6 m minimum, 8 m recommended for new venues -> FIP court specs as verified earlier for rules_b.py (padel-ball-hits-ceiling) and padel-court-dimensions; NOT re-fetched today. Note: Padel Browser claims FIP recommends 7 m; we kept the site's verified 6 m / 8 m and did not cite Padel Browser for it.

## Tactics (2+ sources each)
- Read swing (underneath = lob, step back); serve better vs lobbers; bajada/flat to surprise -> The Padel School, tactics against lobbers.
- Recognise lob sequence; shot by depth (short: víbora/smash; central: bandeja/víbora; deep: let bounce, play after back glass) -> The Padel School, how to deal with lobs. Bandeja for most deep overheads, smash only when finishable; smashing every overhead a common mistake -> Bounce padel strategy (Jul 2026).
- Three zones (back ~2 m / middle / net ~3 m), shot by zone, side-wall caution -> Babolat padel tactics. Ball-height zones (low defend, waist-chest controlled, above shoulder attack); racket back as ball reaches glass -> The Padel School, back glass common errors. Back-glass rebound choices, "height before speed", serve/return choices -> Bounce.
- Block volleys: read early, compact, aim open space/corners, low risk; racket-chest spacing by level -> The Padel School block volleys + Ely Padel Club (LTA ClubSpark).
- Slow balls vs hard hitters, high lob easier than chiquita, let back glass give time -> The Padel School, learn to play slow balls. Don't match pace; higher/deeper/slower; depth > height; lob less if smash is their weapon; ~70% to weaker player, identify in first games, give a full set; play for the break; safe 40-40; one positive instruction at change of ends -> Padel Browser, how to beat a stronger pair.
- Australian formation: server near centre, partner same side, server crosses; pro use, best when a player prefers one side -> The Padel School serve formation. Keeps each player on one side, longer run to net, beginners classic serve; switching formation mid-set allowed (site reply) -> Padel Addict (Spanish).
- Study: 1,089 points, WPT 2020 men, conventional serve to side wall >66%; Australian: T predominant in one configuration -> European Journal of Human Movement 2024 (eurjhm article 870).
- I-formation (tennis): net player crouches on centre line, hand signals behind back -> Wikipedia I-formation (tennis). "Tandem": NOT verified as a padel term (only tennis usage found) -> article says so. "I-formation" rare in padel coaching sources -> stated.
- Invading partner's side: mainly at net; agree roles; risks (open side, weaker shot, friction) -> Padel Addict.
- Lower-level players: practise lob, chiquita, slower bandeja -> The Padel School.
- Sides: left-handers almost always right side -> The Padel School how to choose side; lefty ideal in drive zone, lefty-righty both forehands in centre = advantage, two lefties mirrored, personal comfort matters -> All For Padel.
- Vs lefties: spin/rebounds reversed, short backswing, shift towards dominant side, no lobs down the middle, cross-court lob/fast line lob, position-specific advice -> Padel Addict. Lefties usually right; "divorce zone"; backhand weaker, deep to backhand -> Padel USA.
- Bad patch: diagnose opponents vs own errors; slow start of points; high lobs, sun/wind; one simple target; more diagonals if partner struggling; errors from preparation/movement -> All For Padel.
- Outdoor: wind lob power, sun lobs, wet ball heavy/slides on glass, cold less bounce/hot more, patience, 5-10 min to adapt -> The Padel School outdoor tactics. Wind biggest variable, flatter trajectories, dew/heat, indoor consistent bounce, beginners slight indoor edge but frequency matters -> Padel Browser indoor vs outdoor (Apr 2026).
