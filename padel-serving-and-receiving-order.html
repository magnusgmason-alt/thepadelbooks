Who serves next in padel? The serving and receiving order explained

9 min readBy The Padel AcademyUpdated 23 Oct 2026

In padel the serve alternates between the pairs game by game, and the two partners in each pair take turns at their service games, in an order chosen before each set and fixed for that set (FIP Rule 6.8). Each game starts from the right-hand side and the server alternates boxes after every point (FIP Rule 6.5). Receiving has its own fixed order too, and the rulebook says exactly how to fix mistakes.

The short answer

One player serves a whole game, starting from the right and switching sides after every point (FIP Rule 6.5). The next game is served by a player from the other pair, and partners alternate their service games in an order fixed for the set (FIP Rule 6.8). On the receiving side, the pair decides who receives first at the start of the set, and the two players then receive alternately in that fixed order (FIP Rules 8.2 and 8.3).

What the rules say

Rule 4: the toss. Before the match, a coin toss decides who chooses first. The winner can choose to serve or receive, choose the end of the court, or let the opponents choose.

Rule 6.5: which box. The serve goes diagonally into the receiver's box and must land inside its lines. Every game starts from the right-hand side, and the server alternates between the right and left boxes after each point.

Rule 6.8: the serving order. The order of service is chosen before each set and stays fixed for that set. In practice the standard rotation looks like this, with pair A serving first:

  1. Game 1: pair A, first server (A1).
  2. Game 2: pair B, first server (B1).
  3. Game 3: pair A, the other partner (A2).
  4. Game 4: pair B, the other partner (B2).
  5. Game 5: back to A1, and the cycle repeats until the set ends.

Rules 8.2 to 8.4: the receiving order. In the first game of each set that a pair receives, that pair decides which partner receives first. That player receives the first serve of every game the pair receives in the set, and the two partners then receive alternately (8.2, 8.3). The order is fixed for the set or tie-break. If the order is altered by mistake, play continues that way until the end of the game or tie-break and then goes back to the correct order (8.4).

Rule 6.7: the wrong side. If a player serves from the wrong side, it is corrected as soon as it is noticed. Points already played stand, and a fault on a first serve made from the wrong side still counts.

How this works on court

Because every game starts from the right, the first point of each game is served from the server's right box to the receiver's right box (diagonally opposite). The player who receives first in each game is therefore the one standing on the right, often called the drive side. Points 1, 3, 5 and so on go to the right-side receiver; points 2, 4, 6 go to the left-side receiver, often called the revés side. That is why most pairs simply let the right-side player receive first: it keeps everyone on their usual side.

With golden point scoring (one of the options in FIP Rule 1), the deciding point at deuce raises a practical question: which box? On a golden point (or Star Point), the receiving pair chooses whether to receive on the right or the left (FIP Rule 1). The receivers can't swap positions, and in mixed matches the receiver must be the same sex as the server.

Correct

The server starts every game from the right and alternates boxes each point (Rule 6.5). Partners take turns at their service games in the order set at the start of the set (Rule 6.8). The receiving order is fixed for the set (Rule 8.3).

Incorrect

Starting a game from the left, serving two points in a row from the same box, or swapping who receives first halfway through a set. These are corrected under Rules 6.7 and 8.4.

Real match situations

You win the toss

You can choose to serve, to receive, to pick an end, or to let your opponents choose (FIP Rule 4). Serving first is the popular choice, but some pairs prefer to receive and pick the end with the better light or the sun behind them. Whatever you choose, your opponents get the other decision.

New set, new order

You won the first set with your partner serving first in your pair. Before the second set you can change that and serve first yourself, because the order of service is chosen before each set (FIP Rule 6.8). The receiving order can also be decided afresh in the first game of each set (FIP Rule 8.2). Once chosen, both stay fixed for that set.

You serve the second point from the right again

At 15-0 you serve from the right box instead of the left, and the point is played. When someone notices, you move to the correct side. The point you won stands. If the mistake is spotted after a first-serve fault from the wrong side, that fault still counts and you continue with a second serve from the correct side (FIP Rule 6.7).

The receivers swap by accident

Your opponents' left-side player receives the first point of a game when it should have been their partner. Under Rule 8.4 the game continues with the altered order until it ends, then the pair goes back to the original receiving order. Points played are not replayed.

The wrong partner serves a game

Rule 6.9 covers this: the correct player serves as soon as the mistake is noticed, points already played stand, and a single earlier fault is disregarded. If the game had already finished, keep the altered order until the end of the set. In a social match, fix it calmly and keep the score as it is.

The tie-break at 6-6

The receiving order is fixed for the tie-break as well (FIP Rule 8.3). FIP Rule 1 sets the serving order: the player due to serve serves the first point from the right; the opposing pair serves the next two, starting from the left; then each player serves two points in turn, following the set's order. The next set is started by the pair that did not serve first in the tie-break.

Common misconceptions

  • "The same player in a pair always serves." No. Partners alternate their service games in the fixed order for the set (FIP Rule 6.8).
  • "The order is fixed for the whole match." It is fixed for the set. You can choose again before each new set (FIP Rules 6.8 and 8.2).
  • "Points served from the wrong side are replayed." No. They stand, and the server simply moves to the correct side (FIP Rule 6.7).
  • "A receiving mix-up must be fixed immediately." Under Rule 8.4 you finish the game in the altered order, then revert.
  • "The receiver can choose which box to stand in." "Diagonal" in Rule 3 only defines which opponent receives. Who receives each point is fixed by the receiving order (FIP Rules 8.2 and 8.3) and the alternating boxes (FIP Rule 6.5), wherever the players happen to stand.

Social games vs official matches

An umpire keeps track of the rotation in official play. In social padel, the simplest system is to fix two habits: the server calls the score before every point, and before every game someone says who is serving. If you lose track, work it out from the game count: in the standard rotation, the first server of the set serves games 1, 5 and 9, their partner serves games 3, 7 and 11.

Practical tips

Choose your serving order with the conditions in mind. If one end has the sun in the server's eyes, the player who handles that better should take the games served from that end. Pairs with one stronger server often put that player first, so they serve games 1, 5 and 9 in a full set. Frequently asked questions

Which side do you serve from first in padel?

Always from the right-hand side at the start of each game, then alternating boxes after every point (FIP Rule 6.5).

Do partners take turns serving in padel?

Yes. The pairs alternate games, and the two partners alternate their service games in the order chosen for the set (FIP Rule 6.8).

Can you change who serves first in a new set?

Yes. The order of service is chosen before each set (FIP Rule 6.8), and the receiving order is decided again in the first game of each set (FIP Rule 8.2).

What if you serve from the wrong side?

It is corrected when noticed. Points already played stand, and a first-serve fault made from the wrong side still counts (FIP Rule 6.7).

Who receives the first point of a game?

The player the receiving pair chose at the start of the set. That player receives the first serve of every game the pair receives in that set (FIP Rule 8.2).
